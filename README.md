# Untuk Piaw · 22.10

Versi GitHub Pages dari website ulang tahun Piaw. Website ini statis; foto, surat, dan musik berada di dalam file project.

## Cara menerbitkan

1. Buat repository publik bernama `teaz01.github.io`.
2. Unggah isi folder project ini ke branch `main`.
3. Buka **Settings → Pages**, lalu pilih **GitHub Actions** sebagai sumber deployment.
4. Tunggu workflow selesai. GitHub akan menampilkan alamat website.

Repository dan website akan bersifat publik. Siapa pun bisa membuka atau mengunduh foto, surat, dan audio yang ada di dalamnya.
